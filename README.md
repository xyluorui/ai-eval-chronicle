# AI 评测编年史

大模型与 AI Agent 评测技术发展时间线。从 GLUE 到 Humanity's Last Exam，记录每一个定义 AI 能力边界的评测基准。

## 在线访问

[https://xyluorui.github.io/ai-eval-chronicle/](https://xyluorui.github.io/ai-eval-chronicle/)

## 收录范围

- **通用能力**: MMLU、HELM、BIG-bench 等
- **推理与数学**: GSM8K、MATH、ARC-AGI 等
- **代码能力**: HumanEval、SWE-bench 等
- **Agent 能力**: AgentBench、WebArena、GAIA 等
- **对话与偏好**: MT-Bench、Chatbot Arena 等
- **安全与对齐**: TruthfulQA 等
- **中文评测**: C-Eval、CMMLU 等
- **多模态**: MMMU、MathVista 等
